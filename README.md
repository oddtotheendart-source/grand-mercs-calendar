# Grand Merchant Collective Planner

A player-created planning calendar, guide, and historical resource for the Grand Merchant Collective of Achaea.

## Purpose

The planner is being built to make it easier for both new and established Merchants to find current events, training information, clan scroll references, public historical material, and information about members of the Collective.

## Planned sections

- Achaean game calendar and upcoming events
- Learning and training
- Merchant member directory
- Clan scroll reference
- Events and competitions
- Collective history
- Public submissions and corrections

## Contact

For additions, corrections, or questions in Achaea, contact **Ticca Indasha**.

When submitting calendar information, please include the event name, Achaean date, organizer or sponsoring organization, location, and a public source where possible.

## Updating the Planner

Public information may be submitted in game to Ticca Indasha. A website submission route will be added as the planner develops.

Historical and current information will be kept distinct. Current guidance should be based on current clan scrolls or other public sources; older material will be preserved as historical material rather than silently treated as current procedure.

## Status

Early build. The calendar interface and site structure are under active development.
